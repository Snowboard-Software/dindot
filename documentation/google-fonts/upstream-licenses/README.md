# Upstream name and license review

The attached copies record the notices inspected for this submission on
14 November 2026:

- `DINish-OFL.txt`: [DINish at revision efeeee31](https://github.com/playbeing/dinish/blob/efeeee31/OFL.txt),
  the source revision documented for DINDOT's inputs. It declares no RFN.
- `Altinn-DIN-OFL.txt`: [Altinn-DIN's upstream notice](https://github.com/Altinn/altinn-din/blob/master/OFL-1.1.txt).
  It reserves **Altinn-DIN**, **Altinn-DIN Condensed**, and **Altinn-DIN Expanded**.

DINish's [lineage and acknowledgements](https://github.com/playbeing/dinish#acknowledgements)
also credit Altinn (2019) and Datto (2017), and trace the design to D-DIN by
Charles Nix / Monotype for Datto. Those upstream attributions remain part of
this project's documentation. The original Datto distribution's complete
documentation has not been independently re-audited here.

The proposed family is definitively named **DINDOT**, not any of the named
Altinn families. Nevertheless, both DINDOT and the upstream names refer to
DIN. The Google Fonts checklist asks about RFNs used in whole or in part.
The submission therefore explicitly requests discussion of this shared
element together with the all-caps/abbreviation exception. This record does
not claim a trademark clearance or a Google Fonts naming-policy approval.

The copied upstream notices document the lineage; they do not declare new
Reserved Font Names for DINDOT. The root OFL.txt is the DINDOT license notice.
